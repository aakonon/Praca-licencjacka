## Opis
Repozytorium zawiera skrypt wykorzystany w pracy licencjackiej do automatycznego pobierania danych o ofertach sprzedaży i wynajmu mieszkań z portalu Nieruchomości-online.pl oraz zapisywania wyników do plików Excel.

Skrypt automatycznie pobiera dane z losowo wybranych stron, przelicza ceny podane w euro według kursu NBP, usuwa duplikaty oraz zapisuje wyniki do pliku `.xlsx`.

## Sposób użycia
Po uruchomieniu programu należy wkleić link do pierwszej strony wyników wyszukiwania z wybranymi parametrami, takimi jak miasto, typ rynku, sortowanie oraz pozostałe filtry.
